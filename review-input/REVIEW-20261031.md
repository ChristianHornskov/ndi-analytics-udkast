# Afgrænset visuel rettelse, 31. oktober 2026

Widgeten genbruger nu den faktiske offentlige forsidekode fra Azure. Originalfilerne ligger i homepage-source med kilde og release i provenance.json. Original graf, CSS og klassevælger er bevaret; preview-adapter.js/css tilføjer kun ISIN-kopiering, de tre opsummeringstal, tre års kalender og to links ind i universet. Produktionspolling er slået fra i den genererede kopi, så previewet ikke forlader sin fastlåste release. Intet er ændret på Azure eller Wix.

Porteføljens originale fotografiske temakort er genskabt. De nye nummerfelter og farvede navigationspiller er fjernet. Introduktionen er forkortet, især af hensyn til mobil. Original V18 er urørt.

Kontroller: fem automatiske tests, kildefilers byte-identitet, JS-syntaks, desktop og 390 px mobil; PMINDI/AKK, periodevalg og porteføljelink. Data er den dokumenterede release med rapportdato 30. oktober og kursdato 29. oktober, ikke en ny driftsudgivelse. Grok/Claude-leverancer og samlet mediegennemgang er fortsat separate, udestående dele.
