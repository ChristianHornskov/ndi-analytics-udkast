# Interne tags (ikke offentlige i udkastet)

Indtil compliance har gennemgået dem, er følgende **kun interne** og må ikke vises i UI, URL, chips eller eksport:

- `legacy` / "mistænkt for at være legacy"
- `trump-vinder` / `trump-taber` / politiske vinder-taber-labels

Hvis de findes i rå data, strippes de før render. Offentlig erstatning (hvis nogensinde): neutral formulering a la "Politisk følsom eksponering (told/subsidier)" efter godkendelse.

Se UX-krav.md §0.2 og SPEC C12.
